CUBICALS LIBRARY WEBSITE
------------------------
Open index.html in any browser to view the site.

Folder:
  index.html      page content (text, links, phone, address)
  css/style.css   colours and layout
  js/main.js      menu, photo slider, photo enlarge
  images/         your photos and logo
  favicon.png     browser tab icon

To publish: upload the whole folder to any web host
(Netlify Drop, GitHub Pages, Cloudflare Pages, or your hosting panel).
To change photos: replace files in images/ with the same names.
To change phone/WhatsApp: search 919430371915 in index.html.
