# Cubicals Library Website

Website for **Cubicals Library**, a peaceful, air-conditioned self-study library
in Harmu, Ranchi, for NEET, JEE, UPSC, JPSC, SSC, Banking and Board exam students.

## Features
- Responsive design for phones, tablets and laptops
- Mobile menu and auto-playing photo slider with swipe
- Photo gallery with enlarge view
- Study plans with a WhatsApp enquiry button for each plan
- FAQ section, contact details and Google Map
- Search engine data for local business

## Project structure
```
cubicals-library/
├── index.html      page content
├── css/style.css   colours and layout
├── js/main.js      menu, slider, photo viewer
├── images/         photos and logo
├── favicon.png     browser tab icon
└── README.txt
```

## Run locally
Download the folder and open `index.html` in any browser. No installation needed.

## Publish for free
1. Upload the folder to a GitHub repository.
2. Go to Settings > Pages.
3. Under Source, choose the `main` branch and the root folder, then save.
4. Your site goes live at `https://<your-username>.github.io/<repository-name>/`.
